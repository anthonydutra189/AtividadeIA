# Estrutura
- Use **Orientação a Objetos** com:
    - Encapasulamento 
    - Getter e Setters
    - Construtores 
- Toda classe deve ter a função `Mostrar()` para exibir suas informações
- Use o padrão **Active Records**

## Dependências
Este projeto usa o **MySQL Connector** para connetar ao banco de dados.
